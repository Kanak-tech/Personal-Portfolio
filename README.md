# Personal Portfolio Website

A responsive personal portfolio website built with **HTML, CSS and JavaScript**. It showcases who I am, my skills, my projects and how to contact me.

## Features

- Dark and light theme toggle (the choice is saved in the browser)
- Animated hero section with a typing effect and animated counters
- Sticky header that highlights the current section, plus a scroll progress bar
- About section with education timeline and interests
- Skills section with animated progress bars
- Projects section with category filter (All, Web, AI / ML)
- Contact form with validation and a pop-up message
- Fully responsive for mobile, tablet and desktop

## Technologies Used

| Technology | Purpose |
| --- | --- |
| HTML5 | Page structure |
| CSS3 | Styling, layout, animations, themes |

## How to Run

1. Download the project folder.
2. Keep `index.html`, `style.css` and `script.js` in the same folder.
3. Double-click `index.html` to open it in any modern browser.

No installation or internet server is needed. An internet connection is only used to load the Google Fonts.

If you only want a single file, open `portfolio-single-file.html` instead.

## How to Customize

1. **Name and logo:** replace `Kanak Prajapati` and `KP` in `index.html`.
2. **About and education:** edit the text inside the `#about` section.
3. **Skills:** change the skill names and the `data-level` percentages in the `#skills` section.
4. **Projects:** edit the project cards and put your real demo and source code links in place of `#`.
5. **Contact details:** update the email, GitHub and LinkedIn links in the `#contact` section.
6. **Colors:** change the color values at the top of `style.css` inside `:root`.
7. **Typing text:** edit the `roles` list at the top of `script.js`.
